# Elusive Muse

A Schwung audio effect for Ableton Move that draws a card from Brian Eno and
Peter Schmidt's *Oblique Strategies*. Click the jog wheel and the screen fills
with pixel static and scattered glassy notes. The static clears into one card,
shown whole and centred on the screen, and lands on a soft chord.

Status: design stage. See [DESIGN.md](DESIGN.md).
